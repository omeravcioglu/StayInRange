# Stay In Range

**An online co-op horror FPS made in Unity 6.** Your team is bound by an invisible "collar": if anyone strays more than 30 m from the group for 5 seconds, the whole team is thrown back to the last checkpoint. Push through hospital and lab labyrinths together, fight off zombies, a grabbing creature and magicians, and carry fallen teammates back to life.

---

## Gameplay

- **The collar:**
  - Distance to the team is tracked all the time. From 25 m you get a danger warning; past 30 m a 5-second countdown starts.
  - Lose it and the team resets to the last checkpoint.
  - World markers show where your teammates are.
- **Death isn't game over:**
  - A downed player's body can be picked up and carried to a revive station.
  - While down, the player spectates the team.
  - A full team wipe shows a team-wipe screen and resets to the checkpoint.
- **Enemies:**
  - Zombies, including ambush spawns.
  - A creature ("creep") that grabs a player and drags them away.
  - Magicians that attack at range.
- **Movement:** FPS gunplay, plus a switch to third-person parkour and climbing on marked surfaces.
- **Levels:** hospital wings and lab shafts, partly generated by editor tools from ASCII layouts, with synced traps (sweeping lasers, blinking platforms).
- **Flow:** Menu → Lobby (ready-up, character/skin choice) → Game. A hospital intro cutscene (`Hospitalstart` + Timeline) is in progress.

**Status:** playable prototype. The full co-op loop, three enemy types, pickups, traps and sound effects work, and Windows builds were made. The levels are assembled from store art, and some test scenes and debug logging remain (see *Known leftovers*).

## Tech stack

| Area | What it uses |
|---|---|
| Engine | **Unity 6** (6000.0.32f1), **URP** 17 |
| Networking | **Photon Fusion 2** (2.1.1) in *Shared* mode, with the master client in charge of shared world state. Own code uses about 45 `[Networked]` properties, 19 RPCs and master-client checks throughout. |
| Multiplayer UI | **Clean Multiplayer Pro** (menu, room browser, chat), heavily integrated |
| FPS framework | **Cowsins FPS Engine** (weapons, movement, interaction), bridged to the network |
| AI | **Emerald AI** (enemies), Unity **AI Navigation** |
| Characters | **Malbers Animations** (third-person/parkour controller), **Animation Rigging** |
| Rendering | **FlatKit** stylized shading, post-processing |
| Other | Input System, Cinemachine 3, Splines, ProBuilder, Timeline, Newtonsoft JSON; **ParrelSync** for multi-editor testing |

### Code highlights

- **`Assets/_Integration/Multiplayer/TeamDistanceManager.cs`:** the core collar mechanic. It tracks team distance with a danger zone, a grace timer and a synchronized team reset to the last checkpoint.
- **`Assets/_Integration/FpsNetworkBridge.cs`:** wraps a single-player FPS framework into a networked player, including routing damage to the right authority.
- **`Assets/_Integration/Multiplayer/NetworkWorldActor.cs`:** the master client simulates the enemies. Each client finds its local copy of a scene object from a hash of its scene path, so scene-placed actors need no manual network IDs.
- **`Assets/_Integration/Editor/HospitalWingBuilder.cs`:** builds a hospital wing from an ASCII map, working out walls, corners and doors automatically.
- **`Assets/_Integration/PlayerDownState.cs`** + **`ReviveStation.cs`:** the carry-to-revive loop, where one player physically carries another's body across the level.
